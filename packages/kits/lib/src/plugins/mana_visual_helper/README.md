# 视觉辅助 - VisualHelper

## 使用 - Use

```dart
import 'package:flutter_mana/flutter_mana.dart';
import 'package:flutter_mana_kits/flutter_mana_kits.dart';

void registerPlugin(ManaController controller) {
  controller.registerPlugin(ManaVisualHelper());
}
```
