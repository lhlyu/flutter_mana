# 组件检查

通过“点选组件 / 操作应用”切换检查与业务交互，查看命中候选、父级路径和组件详情。手机默认使用屏幕高度约 78% 的可收起底部面板，桌面保留可拖动浮窗；收起后仍可切换模式并查看选中组件名称。

顶部操作区与下方详情使用独立的滚动控制器。普通手机尺寸下，模式切换、组件摘要、父级路径、导航操作和详情标签固定在顶部，只有详情纵向滚动。极矮窗口或大字体空间不足时，顶部可通过顶部区域内的手势查看溢出内容；滚动详情或在详情边界继续拖动均不会带动顶部。

- **布局**：组件名、Key、尺寸、应用内位置、约束、RenderObject 和可用的创建位置。
- **属性**：按名称或值搜索组件诊断属性，搜索内容按普通文本匹配。
- **原始诊断**：查看并复制 Widget / RenderObject 诊断文本；摘要也可单独复制。
- **导航**：切换同一点击位置的命中候选，或通过父级按钮、路径选择外层组件，范围限定在当前宿主应用内。
- **显示设置**：布局边界、选中区域尺寸、框架内部组件。后两项保留设置；布局边界在退出时恢复原值。

尺寸、位置和高亮随应用帧更新；选中组件离开页面时提示重新点选。创建位置依赖 Widget 创建跟踪，不可用时显示空值。

```dart
import 'package:flutter_mana/flutter_mana.dart';
import 'package:flutter_mana_kits/flutter_mana_kits.dart';

final controller = ManaController(plugins: [ManaWidgetInfoInspector()]);
```

仅支持 Debug 构建。“点选组件”模式会拦截业务触摸事件；切换到“操作应用”后，可直接点击、滚动业务页面，保留当前选中信息。
